# Zenith LineWorks — нийтийн сайт ба лиценз олгогч

**Сайт:** https://nova-xo.github.io/lineworks/
**Татах:** https://github.com/NOVA-XO/lineworks/releases/latest

Энэ repository нь Zenith LineWorks-ийн **нийтийн тал** — танилцуулга сайт,
суулгах файлын тараалт, лицензийн бүртгэл. Програмын эх код энд **байхгүй**;
тэр нь тусдаа хаалттай repository-д байна.

---

## Юу юунаас бүрдэх вэ

| Файл | Юу вэ |
|---|---|
| `index.html`, `download.html`, `license.html` | Сайт. Статик HTML, build алхамгүй. |
| `assets/site.css` | Ганц хэв маягийн файл. Framework, CDN ашиглахгүй. |
| `registry.json` | Олгогдсон лицензийн нийтийн бүртгэл. Робот энд мөр нэмнэ. |
| `.github/ISSUE_TEMPLATE/license-request.yml` | Лиценз хүсэх маягт. |
| `.github/workflows/issue-license.yml` | Хүсэлт ирэхэд ажиллах робот. |
| `tools/issue-license.mjs` | Түлхүүр гаргаж, бүртгэлд нэмж, хариу бичдэг код. |
| `tools/new-keypair.mjs` | Түлхүүрийн хос үүсгэгч. Нэг л удаа ажиллана. |
| `tools/verify-license.mjs` | Шалгагч. Plugin доторх шалгалтыг ижлээр давтана. |

Сайт нь `main` салбарын үндсээс шууд тавигдана (GitHub Pages → Deploy from a
branch → `main` / `(root)`). Робот `registry.json`-ыг push хийхэд Pages өөрөө
дахин барина.

## Лиценз хэрхэн олгогддог вэ

```
Хэрэглэгч маягт бөглөнө
        │
        ▼
  GitHub Issue  ──►  Actions ажиллана
                         │
                         ├─ маягтыг шалгана (дутуу бол буцаана)
                         ├─ ECDSA P-256-оор гарын үсэг зурсан түлхүүр гаргана
                         ├─ registry.json руу нэг мөр нэмж push хийнэ
                         └─ хүсэлт дээр түлхүүрийг хариу бичнэ
```

**Түлхүүр нь өөрөө өөрийгөө батална.** Програм лиценз шалгахдаа ямар ч сервер
рүү залгахгүй — дотроо агуулсан нийтийн түлхүүрээр гарын үсгийг шалгаад
дуусна. Талбарт, сүлжээгүй газар ажиллах ёстой програмд энэ л ганц зөв арга.

Хэрэглэсэн алгоритм нь **ECDSA P-256 + SHA-256**, гарын үсэг нь IEEE-P1363
(64 байт) хэлбэртэй. Ed25519 биш байгаа шалтгаан: .NET 8-д Ed25519 суурьдаа
байхгүй, харин `ECDsa.VerifyData` бий. Ингэснээр Node ба C# хоёр тал аль аль
нь **нэг ч гуравдагч сан** шаардахгүй.

### Түлхүүрийн хэлбэр

```
ZLW1.<b64url(payload JSON)>.<b64url(signature)>
```

`payload` нь лицензийн дугаар, эзэмшигч, байгууллага, төрөл, хугацаа,
төхөөрөмжийн дугаар (хоосон байж болно) агуулна. Гарын үсэг нь
`ZLW1.<payload>` мөрийг бүтнээр нь хамарна.

## Эзэмшигчид: анхны тохиргоо

Нэг удаа хийгдэх дөрвөн зүйл.

**1. Түлхүүрийн хос үүсгэх** — өөрийн компьютер дээр:

```bash
node tools/new-keypair.mjs
```

**2. Хувийн түлхүүрийг GitHub Secret болгох.** Settings → Secrets and
variables → Actions → New repository secret, нэр нь `ZLW_LICENSE_KEY`.
Хувийн түлхүүрийг repository-д **хэзээ ч** бүү оруул.

**3. Нийтийн түлхүүрийг plugin дотор бичих.** Нууц биш — түүнийг мэдсэн хүн
лиценз **зохиож** чадахгүй, зөвхөн **шалгаж** л чадна.

**4. GitHub Pages асаах.** Settings → Pages → Deploy from a branch →
`main` / `(root)`.

> **Хувийн түлхүүрээ нөөцөл.** Алдвал шинийг үүсгэх хэрэгтэй болох ба тэр
> үед өмнө олгосон **бүх лиценз хүчингүй** болно.

## Нууцлал

Нийтийн бүртгэлд ордог зүйл: лицензийн дугаар, байгууллагын нэр, төрөл,
хугацаа, төхөөрөмжийн дугаарын **эхний найм**.

Ордоггүй зүйл: хувь хүний нэр, и-мэйл, төхөөрөмжийн бүтэн дугаар. Эдгээр нь
зөвхөн гарын үсэг зурагдсан түлхүүр дотор — өөрөөр хэлбэл зөвхөн эзэмшигчийн
гарт байна.

Програм өөрөө таны зураг, тооцоог хаашаа ч илгээхгүй.

## Туршилт

```bash
node tools/new-keypair.mjs > keys.txt
sed -n '/BEGIN PRIVATE KEY/,/END PRIVATE KEY/p' keys.txt > private.pem
sed -n '/BEGIN PUBLIC KEY/,/END PUBLIC KEY/p'   keys.txt > public.pem

# ... хуурамч хүсэлтээр түлхүүр гаргаад:
node tools/verify-license.mjs public.pem test.lic
```

Шалгагдах ёстой дөрвөн зүйл: зөв түлхүүр батлагдана, нэг байт өөрчлөхөд
унана, өөр нийтийн түлхүүрээр батлагдахгүй, нэг хүсэлтэд хоёр лиценз
олгогдохгүй.
