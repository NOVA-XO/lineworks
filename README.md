# Zenith LineWorks — нийтийн сайт ба лицензийн портал

**Сайт:** https://nova-xo.github.io/lineworks/
**Татах:** https://github.com/NOVA-XO/lineworks/releases/latest

Энэ repository нь Zenith LineWorks-ийн **нийтийн тал**: танилцуулга сайт, суулгах файлын тараалт,
лицензийн портал. Програмын эх код энд **байхгүй**, хаалттай repository-д хадгалагддаг. Түлхүүр,
нууц үг, хэрэглэгчийн мэдээлэл энэ репод **ордоггүй**.

**Өөрчлөлтийн түүх:** [CHANGELOG.md](CHANGELOG.md).

## Лиценз авах

```
Civil 3D → ZLWLICENSE → «Хүсэлт илгээх…»
        │  account.html?mid=XXXX-XXXX-XXXX-XXXX нээгдэнэ
        ▼
account.html: имэйлээр ирсэн 6 оронтой кодоор нэвтэрнэ
        → нэр, «Компанид ажилладаг» / «Оюутан», байгууллага / сургууль → хүсэлт
        ▼
Зенит Солар хүсэлтийг хянаж батална
        ▼
account.html: «Миний профайл» → «Хуулах» / «.lic татах» → ZLWLICENSE → «Оруулах»
```

**Миний профайл:** нэр, төрөл (компани/оюутан), байгууллага, имэйл; лицензийн төрөл, дугаар,
дуусах огноо ба үлдсэн хоног (30-аас бага үлдвэл «Сунгах хүсэлт»); лицензийн токен; бүртгэлтэй
компьютерүүд.

**Эрх нь сервер дээр шийдэгддэг.** Хэрэглэгч зөвхөн өөрийн мэдээлэл, хүсэлт (хүлээгдэж буй нь 3-аас
ихгүй), лицензээ харна. Батлах, цуцлах, эрх өөрчлөх нь хоёр шаттай баталгаажсан админд л.

**Цуцалсан лиценз** хугацаа нь дуустал офлайнаар ажилласаар байна: plugin интернэтэд
холбогддоггүй. Тиймээс лицензийг богино хугацаатай олгож, сунгалтаар үргэлжлүүлнэ.
